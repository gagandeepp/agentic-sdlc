# Plan 1: Foundation (Milestones 1–2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable, CI-checked monorepo. It has an event-sourced backbone: Pydantic event contract → TypeScript types, MongoDB event store, gap-free EventBus, SSE stream. A React SPA shows a scripted fake SDLC run live in a timeline with agent cards and token metrics.

**Architecture:** FastAPI app (`api/`) holds a `MongoStore` (runs + events collections) and an in-process `EventBus`. The bus serializes appends per run (monotonic `seq`), persists every event, updates a run projection, and fans out to subscribers. `GET /api/runs/{id}/events` streams events over SSE: it catches up from Mongo, then goes live, and resumes via `Last-Event-ID`. A dev-only endpoint plays a scripted fake run through the same bus. The SPA (`web/`) folds events into view state with one idempotent reducer. The reducer is shared by live view now and replay later.

**Tech Stack:**
- API: Python 3.12, uv, FastAPI, Pydantic v2, pydantic-settings, PyMongo async (`AsyncMongoClient`). Tests use pytest, pytest-asyncio, testcontainers, httpx, and asgi-lifespan.
- Web: Node 24, pnpm 12, Vite 8, React 19, TypeScript 6.0, Tailwind 4, Zustand 5, React Router 8, TanStack Virtual, and json-schema-to-typescript. Tests use Vitest 5 and Testing Library.
- Infra: Docker Compose with MongoDB 8.0 and nginx; GitHub Actions for CI.

**Spec:** `docs/superpowers/specs/2026-10-13-agentic-sdlc-design.md`

## Global Constraints

- Python `3.12` (container `python:3.12-slim`); dependencies via uv `0.12.x`; commit `api/uv.lock`.
- Node `24`; pnpm `12.11.2` via corepack (`"packageManager": "pnpm@12.11.2"`); commit `web/pnpm-lock.yaml`.
- TypeScript pinned `~6.0.3`, because typescript-eslint 8.x supports `<6.1.0`.
- MongoDB `mongo:8.0` (matches Atlas). Use the PyMongo native async API (`from pymongo import AsyncMongoClient`), not Motor.
- The event contract lives **only** in `api/app/events/models.py`. `web/src/types/api.ts` is generated by `make types` and never hand-edited.
- Wire format is snake_case JSON. `seq` starts at 1 and is monotonic per run with no gaps.
- Ports: api `8080`, web `5173` (compose maps 5173 → nginx 80), mongo `27017`.
- No secrets in the repo; `.env` is gitignored. Plan 1 needs no third-party credentials.
- Dark theme by default (Tailwind slate palette).
- Before each commit run `make fmt` (ruff format + ruff check --fix). Every commit message ends with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Browser reconnects mid-run** (network blip, server-side overflow, page reload): no gaps and no duplicated timeline entries. Pinned by the bus race test (Task 7), the `Last-Event-ID` test (Task 8), and the reducer resume test (Task 10).
2. **Two producers emit to the same run concurrently** (parallel devs later): `seq` stays unique and contiguous, and subscribers see events in `seq` order. Pinned by concurrent `next_seq` (Task 5) and concurrent emit (Task 7).
3. **Huge tool output** (multi-MB test logs): stored truncated to 16 KB with a flag and the original size, still valid UTF-8. Pinned in Task 4.
4. **Events requested for an unknown run:** immediate 404, never a hanging stream. Pinned in Task 8.
5. **MongoDB unreachable at startup or mid-request:** the app still starts, health returns 503 `degraded`, and API routes return 503 JSON (not a crash or a bare 500). Pinned in Tasks 1 and 8.

`api/app/main.py`:
```python
"""FastAPI application factory."""

import logging
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from typing import Any

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse
from pymongo import AsyncMongoClient
from pymongo.errors import PyMongoError

from app.settings import Settings

log = logging.getLogger(__name__)


def create_app(settings: Settings | None = None) -> FastAPI:
    settings = settings or Settings()

    @asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        client: AsyncMongoClient[dict[str, Any]] = AsyncMongoClient(
            settings.mongo_uri,
            serverSelectionTimeoutMS=settings.mongo_timeout_ms,
            tz_aware=True,
        )
        app.state.mongo = client
        try:
            yield
        finally:
            await client.close()

    app = FastAPI(title="agentic-sdlc", lifespan=lifespan)
    app.state.settings = settings
    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.cors_origins,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    @app.get("/api/health")
    async def health() -> JSONResponse:
        try:
            await app.state.mongo.admin.command("ping")
        except PyMongoError:
            return JSONResponse({"status": "degraded", "mongo": "unreachable"}, status_code=503)
        return JSONResponse({"status": "ok", "mongo": "ok"})

    return app


app = create_app()
```

```python
class AgentToolResultPayload(ContractModel):
    tool_use_id: str
    is_error: bool
    content: str
    truncated: bool = False
    original_size: int | None = None

    @classmethod
    def from_content(
        cls,
        tool_use_id: str,
        content: str,
        *,
        is_error: bool = False,
        limit: int = TOOL_RESULT_LIMIT_BYTES,
    ) -> "AgentToolResultPayload":
        raw = content.encode()
        if len(raw) <= limit:
            return cls(tool_use_id=tool_use_id, is_error=is_error, content=content)
        # errors="ignore" drops a multi-byte character cut in half at the limit
        clipped = raw[:limit].decode(errors="ignore")
        return cls(
            tool_use_id=tool_use_id,
            is_error=is_error,
            content=clipped,
            truncated=True,
            original_size=len(raw),
        )

        assert isinstance(payload, type) and issubclass(payload, ContractModel)
        index[event_type] = payload
    return index
```

```python
    return f"run_{secrets.token_hex(4)}"

    def __init__(self, db: AsyncDatabase[dict[str, Any]]) -> None:
        self._runs = db["runs"]
        self._events = db["events"]
        self._indexes_ready = False

    async def ensure_indexes(self) -> None:
        await self._events.create_index([("run_id", ASCENDING), ("seq", ASCENDING)], unique=True)
        await self._runs.create_index([("created_at", DESCENDING)])
        self._indexes_ready = True

    async def create_run(self, new: NewRun, *, run_id: str | None = None) -> RunRecord:
        if not self._indexes_ready:
            # Mongo may have been down at startup; every run starts here, so the unique
            # (run_id, seq) index always exists before the first event is written.
            await self.ensure_indexes()
        now = datetime.now(UTC)
        record = RunRecord(
            id=run_id or new_run_id(), created_at=now, updated_at=now, **new.model_dump()
        )
        doc = record.model_dump(exclude={"id"})
        doc["_id"] = record.id
        await self._runs.insert_one(doc)
        return record

    async def get_run(self, run_id: str) -> RunRecord | None:
        doc = await self._runs.find_one({"_id": run_id})
        return _run_from_doc(doc) if doc else None

    async def list_runs(self, limit: int = 50) -> list[RunRecord]:
        cursor = self._runs.find().sort("created_at", DESCENDING).limit(limit)
        return [_run_from_doc(doc) async for doc in cursor]

    async def next_seq(self, run_id: str) -> int:
        doc = await self._runs.find_one_and_update(
            {"_id": run_id},
            {"$inc": {"last_seq": 1}},
            projection={"last_seq": 1},
            return_document=ReturnDocument.AFTER,
        )
        if doc is None:
            raise RunNotFound(run_id)
        return int(doc["last_seq"])

    async def insert_event(self, event: RunEvent) -> None:
        await self._events.insert_one(EVENT_ADAPTER.dump_python(event, mode="json"))

    async def list_events_after(self, run_id: str, after_seq: int = 0) -> AsyncIterator[RunEvent]:
        cursor = self._events.find(
            {"run_id": run_id, "seq": {"$gt": after_seq}}, projection={"_id": 0}
        ).sort("seq", ASCENDING)
        async for doc in cursor:
            yield EVENT_ADAPTER.validate_python(doc)

    async def apply_projection(self, event: RunEvent) -> None:
        sets: dict[str, Any] = {"updated_at": event.ts}
        incs: dict[str, Any] = {}
        match event:
            case RunStatusChangedEvent():
                sets["status"] = event.payload.status.value
            case PhaseStartedEvent():
                sets["phase"] = event.phase.value if event.phase else None
            case GateOpenedEvent():
                sets["status"] = RunStatus.WAITING_GATE.value
            case GateResolvedEvent():
                sets["status"] = RunStatus.RUNNING.value
            case BudgetUpdatedEvent():
                sets["spent_usd"] = event.payload.spent_usd
            case AgentUsageEvent():
                usage = event.payload
                incs = {
                    "spent_usd": usage.cost_usd,
                    "tokens.input_tokens": usage.input_tokens,
                    "tokens.output_tokens": usage.output_tokens,
                    "tokens.cache_creation_input_tokens": usage.cache_creation_input_tokens,
                    "tokens.cache_read_input_tokens": usage.cache_read_input_tokens,
                }
            case _ if event.type in _TERMINAL_STATUS:
                sets["status"] = _TERMINAL_STATUS[event.type].value
        update: dict[str, Any] = {"$set": sets}
        if incs:
            update["$inc"] = incs
        await self._runs.update_one({"_id": event.run_id}, update)


def _run_from_doc(doc: dict[str, Any]) -> RunRecord:
    return RunRecord(id=doc.pop("_id"), **doc)
```

```python
"""JSON Schema for the API contract; `make types` turns it into web/src/types/api.ts.

Run: uv run python -m app.schema
"""

import json
from typing import Any

from pydantic import TypeAdapter

from app.events.models import EVENT_ADAPTER
from app.store.mongo import RunRecord


def _strip_property_titles(node: Any) -> Any:
    # json-schema-to-typescript turns every property title into a named alias
    # (RunId, Seq1, Type2, ...); without titles it emits clean inline types.
    if isinstance(node, list):
        return [_strip_property_titles(item) for item in node]
    if not isinstance(node, dict):
        return node
    out = {key: _strip_property_titles(value) for key, value in node.items()}
    props = out.get("properties")
    if isinstance(props, dict):
        out["properties"] = {
            name: {k: v for k, v in prop.items() if k != "title"} if isinstance(prop, dict) else prop
            for name, prop in props.items()
        }
    return out


def api_json_schema() -> dict[str, Any]:
    refs, top = TypeAdapter.json_schemas(
        [
            ("event", "serialization", EVENT_ADAPTER),
            ("run", "serialization", TypeAdapter(RunRecord)),
        ]
    )
    defs = dict(top["$defs"])
    defs["RunEvent"] = {"title": "RunEvent", **refs[("event", "serialization")]}
    schema = {
        "title": "Api",
        "type": "object",
        "additionalProperties": False,
        "required": ["event", "run"],
        "properties": {
            "event": {"$ref": "#/$defs/RunEvent"},
            "run": refs[("run", "serialization")],
        },
        "$defs": defs,
    }
    result: dict[str, Any] = _strip_property_titles(schema)
    return result


if __name__ == "__main__":
    print(json.dumps(api_json_schema(), indent=2, sort_keys=True))
```

`api/app/events/bus.py`:
```python
"""In-process event bus: ordered, persisted appends and gap-free subscriptions.

Appends for a run are serialized by a per-run lock, so `seq` order equals persistence order
equals publish order. A subscriber registers *before* reading the stored backlog. Anything
appended after registration is queued, and anything before it is in the store. Duplicates in
that overlap are dropped by `seq`. One API instance owns all live runs (Cloud Run
max-instances=1), so in-memory fan-out is sufficient.
"""

import asyncio
from collections import defaultdict
from collections.abc import AsyncIterator
from datetime import UTC, datetime

from app.events.models import (
    EVENT_ADAPTER,
    PAYLOAD_BY_TYPE,
    TERMINAL_EVENT_TYPES,
    ContractModel,
    Phase,
    RunEvent,
)
from app.store.mongo import MongoStore


class SubscriberOverflow(Exception):
    """The subscriber fell too far behind; reconnect and catch up from the store."""


class _Subscriber:
    def __init__(self, maxsize: int) -> None:
        self.queue: asyncio.Queue[RunEvent] = asyncio.Queue(maxsize=maxsize)
        self.overflowed = False


class EventBus:
    def __init__(self, store: MongoStore, *, queue_size: int = 1000) -> None:
        self._store = store
        self._queue_size = queue_size
        self._locks: defaultdict[str, asyncio.Lock] = defaultdict(asyncio.Lock)
        self._subscribers: defaultdict[str, set[_Subscriber]] = defaultdict(set)

    async def emit(
        self,
        run_id: str,
        event_type: str,
        payload: ContractModel,
        *,
        phase: Phase | None = None,
        agent_id: str | None = None,
    ) -> RunEvent:
        expected = PAYLOAD_BY_TYPE.get(event_type)
        if expected is None:
            raise ValueError(f"unknown event type {event_type!r}")
        if not isinstance(payload, expected):
            raise ValueError(
                f"{event_type} expects {expected.__name__}, got {type(payload).__name__}"
            )
        async with self._locks[run_id]:
            seq = await self._store.next_seq(run_id)
            event = EVENT_ADAPTER.validate_python(
                {
                    "run_id": run_id,
                    "seq": seq,
                    "ts": datetime.now(UTC),
                    "type": event_type,
                    "phase": phase,
                    "agent_id": agent_id,
                    "payload": payload.model_dump(),
                }
            )
            await self._store.insert_event(event)
            await self._store.apply_projection(event)
            self._publish(event)
        return event

    async def subscribe(self, run_id: str, after_seq: int = 0) -> AsyncIterator[RunEvent]:
        subscriber = _Subscriber(self._queue_size)
        async with self._locks[run_id]:
            self._subscribers[run_id].add(subscriber)
        last = after_seq
        try:
            async for event in self._store.list_events_after(run_id, after_seq):
                yield event
                last = event.seq
                if event.type in TERMINAL_EVENT_TYPES:
                    return
            while True:
                if subscriber.overflowed and subscriber.queue.empty():
                    raise SubscriberOverflow(run_id)
                event = await subscriber.queue.get()
                if event.seq <= last:
                    continue
                yield event
                last = event.seq
                if event.type in TERMINAL_EVENT_TYPES:
                    return
        finally:
            self._subscribers[run_id].discard(subscriber)

    def _publish(self, event: RunEvent) -> None:
        for subscriber in list(self._subscribers[event.run_id]):
            try:
                subscriber.queue.put_nowait(event)
            except asyncio.QueueFull:
                subscriber.overflowed = True
                self._subscribers[event.run_id].discard(subscriber)
```

```python
def parse_sse(body: str) -> list[tuple[int, dict[str, Any]]]:
    """Return (id, data) for every SSE message block; comments and retry lines are skipped."""
    messages: list[tuple[int, dict[str, Any]]] = []
    for block in body.split("\n\n"):
        fields = dict(line.split(": ", 1) for line in block.splitlines() if ": " in line)
        if "id" in fields and "data" in fields:
            messages.append((int(fields["id"]), json.loads(fields["data"])))
    return messages
```

```python
"""Server-Sent Events framing with keep-alive pings.

Events are pumped through a queue so that idle waits can time out (to send a ping) without
cancelling the underlying subscription generator.
"""

import asyncio
import contextlib
import logging
from collections.abc import AsyncIterator

from app.events.bus import SubscriberOverflow
from app.events.models import EVENT_ADAPTER, RunEvent

log = logging.getLogger(__name__)

RETRY = "retry: 2000\n\n"
PING = ": ping\n\n"


def format_event(event: RunEvent) -> str:
    # dump_json escapes newlines inside strings, so the payload is always a single data line
    return f"id: {event.seq}\ndata: {EVENT_ADAPTER.dump_json(event).decode()}\n\n"


async def sse_stream(events: AsyncIterator[RunEvent], *, ping_seconds: float) -> AsyncIterator[str]:
    queue: asyncio.Queue[RunEvent | Exception | None] = asyncio.Queue()

    async def pump() -> None:
        try:
            async for event in events:
                await queue.put(event)
            await queue.put(None)
        except Exception as exc:  # handed to the stream loop below
            await queue.put(exc)

    task = asyncio.create_task(pump())
    try:
        yield RETRY
        while True:
            try:
                item = await asyncio.wait_for(queue.get(), timeout=ping_seconds)
            except TimeoutError:
                yield PING
                continue
            if item is None:
                return
            if isinstance(item, SubscriberOverflow):
                # Closing without a terminal event makes EventSource reconnect with
                # Last-Event-ID, which catches up from the store.
                return
            if isinstance(item, Exception):
                log.error("event stream failed", exc_info=item)
                return
            yield format_event(item)
    finally:
        task.cancel()
        with contextlib.suppress(asyncio.CancelledError):
            await task
```

```python
import asyncio
import logging
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from typing import Any

from fastapi import FastAPI, Request

from fastapi.responses import JSONResponse

def create_app(settings: Settings | None = None) -> FastAPI:
    settings = settings or Settings()

    @asynccontextmanager
    async def lifespan(app: FastAPI) -> AsyncIterator[None]:
        client: AsyncMongoClient[dict[str, Any]] = AsyncMongoClient(
            settings.mongo_uri,
            serverSelectionTimeoutMS=settings.mongo_timeout_ms,
            tz_aware=True,
        )
        store = MongoStore(client[settings.mongo_db])
        try:
            await store.ensure_indexes()
        except PyMongoError as exc:
            # Start anyway: /api/health reports the outage, requests get 503, and
            # MongoStore.create_run retries the indexes once Mongo is back.
            log.warning("MongoDB unavailable at startup: %s", exc)
        background: set[asyncio.Task[None]] = set()
        app.state.mongo = client
        app.state.store = store
        app.state.bus = EventBus(store, queue_size=settings.subscriber_queue_size)
        app.state.background_tasks = background
        try:
            yield
        finally:
            for task in background:
                task.cancel()
            await asyncio.gather(*background, return_exceptions=True)
            await client.close()

    app = FastAPI(title="agentic-sdlc", lifespan=lifespan)
    app.state.settings = settings
    app.add_middleware(
        CORSMiddleware,
        allow_origins=settings.cors_origins,
        allow_methods=["*"],
        allow_headers=["*"],
    )

    @app.exception_handler(PyMongoError)
    async def database_unavailable(_: Request, exc: PyMongoError) -> JSONResponse:
        log.warning("database error: %s", exc)
        return JSONResponse({"detail": "database unavailable"}, status_code=503)

    @app.get("/api/health")
    async def health() -> JSONResponse:
        try:
            await app.state.mongo.admin.command("ping")
        except PyMongoError:
            return JSONResponse({"status": "degraded", "mongo": "unreachable"}, status_code=503)
        return JSONResponse({"status": "ok", "mongo": "ok"})

    app.include_router(runs_router)
    return app


app = create_app()
```

```python
def _log_failure(task: asyncio.Task[None]) -> None:
    if not task.cancelled() and task.exception() is not None:
        log.error("fake run failed", exc_info=task.exception())


@router.post("/fake-runs", status_code=201)
async def start_fake_run(
    request: Request, speed: Annotated[float, Query(gt=0, le=100_000)] = 1.0
) -> RunRecord:
    store: MongoStore = request.app.state.store
    bus: EventBus = request.app.state.bus

    task.add_done_callback(background.discard)
```

```ts
import type { GateOpenedEvent, Phase, Role, RunEvent, RunStatus } from '../types/api'

export type AgentStatus = 'idle' | 'thinking' | 'tool' | 'waiting' | 'done' | 'failed'

export interface TokenTotals {
  input: number
  output: number
  cacheCreation: number
  cacheRead: number
}

export interface AgentView {
  id: string
  role: Role
  model: string
  status: AgentStatus
  tokens: TokenTotals
  costUsd: number
  turns: number
  contextTokens: number | null
  contextMax: number | null
}

export interface RunViewState {
  runId: string | null
  lastSeq: number
  status: RunStatus | 'unknown'
  phase: Phase | null
  requirement: string | null
  budgetUsd: number | null
  spentUsd: number
  agents: Record<string, AgentView>
  agentOrder: string[]
  tokens: TokenTotals
  timeline: RunEvent[]
  openGate: GateOpenedEvent | null
  activeAgentId: string | null
  prUrl: string | null
}

export const emptyTokens = (): TokenTotals => ({ input: 0, output: 0, cacheCreation: 0, cacheRead: 0 })

export function initialRunState(runId: string | null = null): RunViewState {
  return {
    runId,
    lastSeq: 0,
    status: 'unknown',
    phase: null,
    requirement: null,
    budgetUsd: null,
    spentUsd: 0,
    agents: {},
    agentOrder: [],
    tokens: emptyTokens(),
    timeline: [],
    openGate: null,
    activeAgentId: null,
    prUrl: null,
  }
}

/** All input tokens the model processed: fresh + written to cache + read from cache. */
export const totalInput = (t: TokenTotals): number => t.input + t.cacheCreation + t.cacheRead

export function cacheHitRatio(t: TokenTotals): number {
  const total = totalInput(t)
  return total === 0 ? 0 : t.cacheRead / total
}

const addTokens = (a: TokenTotals, b: TokenTotals): TokenTotals => ({
  input: a.input + b.input,
  output: a.output + b.output,
  cacheCreation: a.cacheCreation + b.cacheCreation,
  cacheRead: a.cacheRead + b.cacheRead,
})

function updateAgent(
  state: RunViewState,
  agentId: string | null,
  update: (agent: AgentView) => AgentView,
): RunViewState {
  const agent = agentId ? state.agents[agentId] : undefined
  if (!agentId || !agent) return state
  return { ...state, agents: { ...state.agents, [agentId]: update(agent) } }
}

const setStatus = (state: RunViewState, agentId: string | null, status: AgentStatus) =>
  updateAgent(state, agentId, (a) => ({ ...a, status }))

export function reduceEvent(state: RunViewState, event: RunEvent): RunViewState {
  if (event.seq <= state.lastSeq) return state // already applied (reconnect overlap)
  const next: RunViewState = {
    ...state,
    runId: state.runId ?? event.run_id,
    lastSeq: event.seq,
    timeline: [...state.timeline, event],
  }
  switch (event.type) {
    case 'run.created':
      return {
        ...next,
        status: 'pending',
        requirement: event.payload.requirement,
        budgetUsd: event.payload.budget_usd,
      }
    case 'run.status_changed':
      return { ...next, status: event.payload.status }
    case 'run.completed':
      return { ...next, status: 'completed', prUrl: event.payload.pr_url ?? next.prUrl, activeAgentId: null }
    case 'run.failed':
      return { ...next, status: 'failed', activeAgentId: null }
    case 'run.aborted':
      return { ...next, status: 'aborted', activeAgentId: null }
    case 'run.interrupted':
      return { ...next, status: 'interrupted', activeAgentId: null }
    case 'phase.started':
      return { ...next, phase: event.phase ?? next.phase }
    case 'agent.started': {
      const id = event.agent_id
      if (!id) return next
      const existing = next.agents[id]
      const agent: AgentView = existing
        ? { ...existing, model: event.payload.model, status: 'thinking' }
        : {
            id,
            role: event.payload.role,
            model: event.payload.model,
            status: 'thinking',
            tokens: emptyTokens(),
            costUsd: 0,
            turns: 0,
            contextTokens: null,
            contextMax: null,
          }
      return {
        ...next,
        agents: { ...next.agents, [id]: agent },
        agentOrder: existing ? next.agentOrder : [...next.agentOrder, id],
        activeAgentId: id,
      }
    }
    case 'agent.text':
    case 'agent.thinking':
    case 'agent.tool_result':
      return setStatus(next, event.agent_id, 'thinking')
    case 'agent.tool_call':
      return setStatus(next, event.agent_id, 'tool')
    case 'agent.usage': {
      const p = event.payload
      const delta: TokenTotals = {
        input: p.input_tokens,
        output: p.output_tokens,
        cacheCreation: p.cache_creation_input_tokens,
        cacheRead: p.cache_read_input_tokens,
      }
      const totals = { ...next, tokens: addTokens(next.tokens, delta), spentUsd: next.spentUsd + p.cost_usd }
      return updateAgent(totals, event.agent_id, (a) => ({
        ...a,
        tokens: addTokens(a.tokens, delta),
        costUsd: a.costUsd + p.cost_usd,
        turns: a.turns + 1,
        contextTokens: p.context_tokens ?? a.contextTokens,
        contextMax: p.context_max ?? a.contextMax,
      }))
    }
    case 'agent.finished': {
      const finished = setStatus(next, event.agent_id, event.payload.ok ? 'done' : 'failed')
      return {
        ...finished,
        activeAgentId: finished.activeAgentId === event.agent_id ? null : finished.activeAgentId,
      }
    }
    case 'budget.updated':
      // Authoritative spend (from the credential proxy in later plans).
      return { ...next, spentUsd: event.payload.spent_usd, budgetUsd: event.payload.budget_usd }
    case 'gate.opened':
      return { ...next, status: 'waiting_gate', openGate: event }
    case 'gate.resolved':
      return { ...next, status: 'running', openGate: null }
    case 'pr.opened':
    case 'pr.ready':
      return { ...next, prUrl: event.payload.url }
    default:
      return next
  }
}

export const reduceEvents = (state: RunViewState, events: RunEvent[]): RunViewState =>
  events.reduce(reduceEvent, state)
```

```tsx
import { useVirtualizer } from '@tanstack/react-virtual'
import { useEffect, useRef } from 'react'
import type { RunEvent } from '../../types/api'
import { describeEvent, type Tone } from './describeEvent'

const TONE: Record<Tone, string> = {
  neutral: 'text-slate-200',
  info: 'text-sky-300',
  success: 'text-emerald-300',
  warning: 'text-amber-300',
  danger: 'text-red-400',
}

const time = (ts: string) => new Date(ts).toLocaleTimeString([], { hour12: false })

export function Timeline({ events, follow = true }: { events: RunEvent[]; follow?: boolean }) {
  const parentRef = useRef<HTMLDivElement>(null)
  const virtualizer = useVirtualizer({
    count: events.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 52,
    overscan: 8,
    initialRect: { width: 380, height: 640 },
  })

  useEffect(() => {
    if (follow && events.length > 0) virtualizer.scrollToIndex(events.length - 1, { align: 'end' })
  }, [follow, events.length, virtualizer])

  if (events.length === 0) {
    return <p className="p-4 text-sm text-slate-500">Waiting for events…</p>
  }

  return (
    <div ref={parentRef} role="log" aria-label="Run timeline" className="h-full overflow-auto">
      <ol className="relative w-full" style={{ height: virtualizer.getTotalSize() }}>
        {virtualizer.getVirtualItems().map((item) => {
          const event = events[item.index]!
          const summary = describeEvent(event)
          return (
            <li
              key={event.seq}
              data-index={item.index}
              ref={virtualizer.measureElement}
              className="absolute left-0 top-0 w-full border-b border-slate-900 px-4 py-2"
              style={{ transform: `translateY(${item.start}px)` }}
            >
              <div className="flex items-baseline gap-2">
                <span className="font-mono text-[11px] text-slate-500">{time(event.ts)}</span>
                <span className={`text-sm font-medium ${TONE[summary.tone]}`}>{summary.title}</span>
              </div>
              {summary.detail && <p className="truncate text-xs text-slate-400">{summary.detail}</p>}
            </li>
          )
        })}
      </ol>
    </div>
  )
}
```

```ts
export const API_BASE: string = import.meta.env.VITE_API_URL ?? ''

export class ApiError extends Error {
  constructor(
    readonly status: number,
    body: string,
  ) {
    super(`API ${status}: ${body}`)
  }
}

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const response = await fetch(`${API_BASE}${path}`, init)
  if (!response.ok) throw new ApiError(response.status, await response.text())
  return (await response.json()) as T
}
```

```ts
import { useEffect } from 'react'
import { eventsUrl } from '../lib/api'
import { useRunStore } from '../store/runStore'
import type { RunEvent } from '../types/api'

const TERMINAL = new Set<RunEvent['type']>(['run.completed', 'run.failed', 'run.aborted', 'run.interrupted'])

/**
 * Streams a run's events into the run store. EventSource reconnects on its own and sends
 * Last-Event-ID, and the reducer ignores already-seen seqs, so reconnects never duplicate.
 */
export function useRunEvents(runId: string): void {
  const reset = useRunStore((s) => s.reset)
  const apply = useRunStore((s) => s.apply)

  useEffect(() => {
    reset(runId)
    const source = new EventSource(eventsUrl(runId))
    let buffer: RunEvent[] = []
    let frame = 0
    const flush = () => {
      frame = 0
      const batch = buffer
      buffer = []
      apply(batch)
    }
    source.onmessage = (message: MessageEvent<string>) => {
      const event = JSON.parse(message.data) as RunEvent
      buffer.push(event)
      if (frame === 0) frame = requestAnimationFrame(flush) // one store update per frame
      if (TERMINAL.has(event.type)) source.close()
    }
    return () => {
      if (frame !== 0) cancelAnimationFrame(frame)
      source.close()
    }
  }, [runId, reset, apply])
}
```
